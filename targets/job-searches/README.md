# Job Target Files

Create one markdown file per job search target in this folder.

## Recommended Filename

YYYY-MM-DD_company_role_location.md

Example:

2026-08-03_companyX_senior-data-architect_munich.md

## Required Inputs per File

- Prioritized top requirements
- Must-have and nice-to-have split
- ATS keyword set
- Tailoring decision notes

## Template

Start from:

- job-requirements-template.md
