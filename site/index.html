Featured case

AI-agent automation for VSS data-model governance

BMW's VSS repo is the data model behind the Vehicle Shadow stream, consumed by 180+ backend applications. Manual PR review, board triage, release orchestration and CI-fixing consumed the equivalent of ~3 full-time employees — and non-technical stakeholders couldn't contribute without engineering support.

What I built

  • 7 purpose-built AI agents orchestrating ~15 reusable skills: auto-triage CI failures, auto-rebase conflicts, classify EU Data Act requirements, generate changelogs and version bumps, sort the release board.
  • "VSS Explorer" self-service UI — contributors without repo access submit signal requests directly; a backend pipeline turns them into structured issues and auto-generates compliant PRs, removing the git/PR literacy barrier.
  • Cost-aware LLM tooling — a linter + rewriter benchmarked across 3 model tiers to pick the most cost-efficient option at equal quality.

Impact

  • Automated away work equal to ~3 FTEs (~€350k/year) while serving 45+ regular contributors.
  • Sustained a weekly release cadence with far less manual overhead.
  • Delivered in parallel with a strategic .vspec → GraphQL (S2DM) data-model migration for the same 180+ applications.
