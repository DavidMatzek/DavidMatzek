Featured case

AI-agent automation for VSS data-model governance

BMW's VSS (Vehicle Signal Specification) repo is the data model behind the Vehicle Shadow stream, consumed by 180+ backend applications. Manual pull-request (PR) review, board triage, release orchestration and CI-fixing consumed the equivalent of ~3 full-time employees — split across internal effort and external consultants, right as that consultant budget was cut. Non-technical stakeholders couldn't contribute without engineering support.

What I built

  • 7 purpose-built AI agents orchestrating ~15 reusable skills: auto-triage CI failures, auto-rebase conflicts, classify EU Data Act requirements, generate changelogs and version bumps, sort the release board.
  • "VSS Explorer" self-service UI — contributors without repo access submit signal requests directly; a backend pipeline turns them into structured issues and auto-generates compliant PRs, removing the git/PR literacy barrier.
  • Cost-aware LLM tooling — a linter + rewriter benchmarked across 3 model tiers to pick the most cost-efficient option at equal quality.

Impact

  • Removed work equal to ~3 FTEs (~€350k/year) and the external consultant dependency, while serving 45+ regular contributors.
  • Sustained a weekly release cadence through the budget cut, redirecting freed budget to other constrained projects.
  • Delivered in parallel with a strategic .vspec → GraphQL (S2DM) data-model migration for the same 180+ applications.

Agentic workflow design · CI/CD engineering · self-service process redesign · cost-aware LLM decisions · multi-year migration alongside live operations.

Key terms

Plain-language definitions for the domain acronyms used above.

COVESA
Connected Vehicle Systems Alliance — the open industry body that maintains the VSS standard.
VSS
Vehicle Signal Specification — COVESA's open standard for modeling vehicle data in one shared vocabulary.
FTE
Full-Time Equivalent — one person's full-time workload; “~3 FTEs removed” means roughly three people's worth of manual work is no longer needed.
MBSE
Model-Based Systems Engineering — designing from one machine-checkable model instead of scattered documents.
CI/CD
Continuous Integration / Continuous Delivery — automated build, test, and release pipelines.
E/E · ECU
A vehicle's Electrical/Electronic architecture; an ECU (Electronic Control Unit) is one of the many onboard computers it links.
MCP
Model Context Protocol — an open standard that lets AI agents securely use external tools and data.
EU Data Act
EU regulation governing access to and sharing of connected-product data, including vehicle data.
PR
Pull Request — a proposed code change submitted for review before it is merged.
LLM
Large Language Model — the class of AI models the agents are built on.
